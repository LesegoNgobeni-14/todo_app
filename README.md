# Todo App

A local first todo application built with Next.js and SQLite

## Features

- Create tasks
- Edit tasks
- Archive tasks (tasks are never deleted)
- View archived tasks
- Sort tasks by topic, status, or due date
- Highlight overdue tasks
- Persistent local storage using SQLite

## Quick Start

```bash
git clone https://github.com/LesegoNgobeni-14/todo_app.git
cd todo_app
npm install
npm run dev
```

Open **http://localhost:3000** in your browser.

## Running Tests

```bash
npm test
```
